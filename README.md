## Deskripsi

KampusHub adalah halaman papan pengumuman kampus yang dibuat
untuk menampilkan berbagai informasi kepada mahasiswa.
Halaman ini menampilkan pengumuman akademik, beasiswa,
dan informasi perpustakaan.

Website dibuat menggunakan HTML dan CSS tanpa menggunakan
JavaScript atau React.
